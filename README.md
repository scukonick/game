# Dodge & Shoot Game

A fast-paced browser game where you dodge falling obstacles and shoot them down to survive!

## Play Now

[Play the game here!](https://scukonick.github.io/game/)

## Features

- **Dodge or Destroy** - Move left/right to dodge obstacles or shoot them down
- **Armored Obstacles** - Gray obstacles take 3 hits to destroy
- **Power-ups**:
  - ⭐ Score Boost (+20 points)
  - ⚡ Rapid Fire (faster shooting)
  - ◆ Triple Shot (3 bullets at once)
  - ⏱ Slow Motion (slow down obstacles)
- **Progressive Difficulty** - Game speeds up as you score more points
- **Sound Effects** - Synthesized audio feedback
- **Resource Panel** - Track your shooting cooldown, active powers, and stats
- **High Score** - Saved locally in your browser

## Controls

- **Arrow Keys** or **A/D** - Move left/right
- **Spacebar** - Shoot

## How to Play

1. Dodge or shoot the falling colored obstacles
2. Gray armored obstacles need 3 hits to destroy
3. Collect power-ups for temporary abilities
4. Survive as long as possible and beat your high score!

## Technology

- Pure HTML5 Canvas
- Vanilla JavaScript
- Web Audio API for sound
- LocalStorage for high scores

## Local Development

Simply open `index.html` in your browser - no build process needed!
